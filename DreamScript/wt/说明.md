# DreamScript —— 剧本 app（纯渲染）

`/scripts/` 下的剧本 md → 剧本集画廊 → 阅读页；Courier Prime 12pt、Letter 纸面，**只读**。

## 打开

- 开发面：`?wt=<uid>` → 画廊；点卡片进阅读页
- 深链：`?wt=<uid>&app=/scripts/剧本.md`

## 文件

| 文件 | 是什么 |
|---|---|
| `scripts/剧本.md` | 唯一保留的剧本作品（题头 + 场景节 + 元素 bullet） |
| `render/实现.md` | 件库：`jsx@script`（纯渲染排版）+ `print@css`（版式 CSS + 字体） |
| `appscript.md` | 剧本集 app：画廊（封面）与阅读页（hash 路由 `/doc/<path>`） |
| `attic/` | 旧一代实现、demo、研究文档与导出产物（PAPER 编辑器、M0 备份、剧本2.md、docs、observe、minasrc/routerapp、导出/） |

## 会做什么

- **看**：标准剧本排版（Courier · slugline 大写 · 角色居中 · 台词缩进 · 转场右对齐），打印走 `@page` Letter 纸面。
- **不做**：编辑 / 写回 / 导入导出 / 模板切换（旧能力已移除，代码归档在 `attic/`）。

## 渲染策略

见 `/.mds/ui.md`：只声明 `std` + `SCRIPT` + `SCREEN` + `SCRIPT_APP`，match 只有 `SCRIPT: /scripts/::..*[h1]`。
