# 格式专题 · 标准剧本 ⇄ md

专题问题：**一套标准剧本格式，映射成 md 应该长什么样**。验收判据（本轮先立四条）：

1. **纯 md 手写顺手** —— 写剧本的人不该为了标记类型而多敲一堆东西。
2. **可逆** —— md ⇄ 标准剧本（文本载体）· md ⇄ 结构化数据（JSON 载体）。
3. **可寻址** —— 一个元素 = 一个可定位节点（写回才能是一行的事）。
4. **渲染器派生** —— 版式、分页、页码这类东西**不进 md**，由渲染器算。

## 一、已查资料与关键事实

| 来源 | 关键事实 |

## 二、从资料里读出来的三条硬结论

- **大小写判据在中文里失效** —— Fountain 靠「全大写 = 角色名」，中文剧本没有大小写 ⇒ 若照抄 Fountain，中文剧本无法识别角色名。**md 映射必须给角色名显式标记**。
- **分页/页码/MORE/(CONT'D)/CONTINUED 不该进 md** —— Fountain 官方口径：源文件只存显式分页；其余由应用算。这与判据 4 一致。
- **文本载体是有损的**（样式、双人对话、居中都会丢） ⇒ 要无损必须另有一个结构化载体（元素序列），两者都由同一份 md 派生。

## 三、md 符号占用表（本设计的分工）

| md 符号 | 本设计里的含义 | 依据 |
|---|---|---|
| `# ` h1 | 剧本名（题头页的首行） | md 原生：文档标题 |
| `- 键: 值` | 题头页字段（编剧/稿次/日期/联系方式） | md 原生：列表；值可一行一项 |
| `## ` h2 | **场景头（标题文本即 slug）** | md 原生：章节 = 场景（认领单元） |
| `### ` h3+ | 特殊头（MONTAGE / INSERT / FLASHBACK / INTERCUT）与幕/节 | 同上，次级结构 |
| `**名字**` 独占一行 | **角色名**（可带扩展 `(V.O.)` `(O.S.)`） | 与大小写无关 ⇒ **中文可用**；独占一行是判据 |
| `**文字**` 行内 | 强调（md 原生） | 与上一行不冲突（靠「独占一行」区分） |
| `(…)` 独占一行 | 副语言 | 与动作里以括号开头的句子靠「整行就是括号」区分 |
| 其余段落 | 动作 | 兜底（Fountain 同款：拿不准就是动作） |
| `> 文字` | 转场（传统上全大写且以 `TO:` 结尾） | md 原生：引用块；对中文也成立（不靠大写） |
| `> 文字 <` | 居中文字 | Fountain 同款两侧尖括号 |
| 行末 `^` | 双人（同时）对话：接在第二个角色名行尾 | Fountain 同款 |
| `---` | 强制分页（电视稿的幕断、封面页） | md 原生：分隔线 |
| `<!-- … -->` | 注释（写作批注与弃稿合一） | md 原生：注释（渲染时不可见） |

## 四、元素 → md 映射表

| 标准元素 | md 形式 | 解析判据 | 往返备注 |
|---|---|---|---|
| 题头页 Title/Credit/Author/Draft date/Contact | h1 之下 `- 编剧: …` 等 | h1 与第一个 h2 之间的列表 | 与 Fountain 的 `Key: value` 一一对应，只是换成列表更 md |
| 场景头 | `## INT. AUDITION OFFICE - 下午` | h2 标题 | 场号写 `#12#`（Fountain）；**场景名 = 标题文本** ⇒ 改名即改地址 |
| 动作 | 普通段落 | 兜底 | 行内换行保留（一行一段 or 软换行待定） |
| 角色名（含扩展） | `**MIA (V.O.)**` | 独占一行的粗体段落 | 扩展 `(V.O.)/(O.S.)/(CONT'D)` 属于名字的一部分 |
| 台词 | 紧跟角色名（或副语言）之后的段落 | 位置：前一个元素是角色名或副语言 | 连续多段 = 同一段台词的换行 |
| 副语言 | `(紧张)` | 整行就是括号 | 在台词序列内 |
| 转场 | `> CUT TO:` | 引用块且不以 `<` 收尾 | 中文体例也成立 |
| 双人对话 | 第二个角色名行末 `^` | 行末 `^` | |
| 特殊头 | `### MONTAGE` … `### END MONTAGE` | h3 标题 | 结束标记也写作 h3 |
| 歌词（可选） | `~ 一行` | 行首 `~` | Fountain 同款 |
| 批注/弃稿 | `<!-- … -->` | 注释 | 比 `[[ ]]` 与 `/* */` 更 md |

## 五、派生清单（**不进 md**，由渲染器算）

- 分页位置与页码（含首页不编号、右上 ½in 带句点）；台湾体例的「页尾居中」也在这里。
- `(MORE)` / `(CONT'D)` / `CONTINUED:` —— 完全由分页结果决定。
- 缩进与列宽（角色 3.7in、副语言 3.1in、台词 2.5→6.0in、转场右齐）、行距、字体。
- 大小写变换（slug/角色/转场大写）—— **md 里保留作者原样**，渲染时按体例变换。
- 对话归属（谁在说）：由「紧跟角色名」这条位置关系决定，不额外存储。
- **中文体例的 `角色：台词` 同行形态、`△` 动作前缀**：渲染期或导出期按体例生成（存储里保持「角色名独占一行 + 台词另段」）。

## 六、三案对比与推荐

| 方案 | 手写顺手 | 无歧义 | 可寻址 | 中文可用 | 判断 |
|---|---|---|---|---|---|
| A 现行：每行 `- 类型: 文本` | ✗ 每行多敲 `- 台词: ` | ✓ | ✓ 一个 bullet 一节点 | ✓ | 已跑通、可写回；**作为退路保留** |
| B 纯 Fountain 文本（整块代码围栏） | ✓ 最顺手 | 靠惯例 | ✗ 整块一节点 | ✗ 大写判据失效 | 只宜作导入/导出格式 |
| C **md 原生符号 + 位置判据**（本推荐） | ✓ 标记极少 | ✓ 判据明确（独占一行/位置） | ✓ 段落即节点 | ✓ 不依赖大小写 | **推荐**：与 md 语义同构，导入/导出各写一个转换器 |
